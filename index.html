📝 How to Add a New Assignment Every Day

Adding new assignments takes less than 30 seconds! You never need to write or change any CSS code.

1

Find Your Section

Open index.html in your editor and scroll to the section (HTML, CSS, JavaScript, React, etc.).

2

Copy The Card Snippet

Copy the card block below and paste it right inside the <div class="assignment-grid"> container.

3

Update 3 Details

Change: Day number, Assignment name, and the file link in href="...". Save the file!

📋 Ready-To-Copy Card Snippet:

<!-- COPY AND PASTE THIS SNIPPET FOR EVERY NEW ASSIGNMENT -->
<div class="assignment-card">
  <div class="card-top">
    <span class="day-badge">Day 4</span>
    <span class="status-badge">Completed</span>
  </div>
  <h3 class="assignment-title">Day 4 - My New Assignment Title</h3>
  <p class="assignment-desc">Brief description of the topics practiced today.</p>
  <a href="HTML/Day4/index.html" class="btn-card" target="_blank">Open Assignment &rarr;</a>
</div>
