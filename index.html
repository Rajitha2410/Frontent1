How to Add a New Assignment Tomorrow

This portal automatically links your local assignments and connects with your GitHub repository (Rajitha2410/Frontent1). Follow these 3 simple steps:

1 Create Your Assignment Folder & File

Save your new assignment inside its folder, for example:
JAVA SCRIPT/Assignment/Day21/index.html

2 Add the Entry in `index.html` (Dataset)

Open index.html and find the ASSIGNMENTS_DATA array. Add one item: 

{
  category: "javascript",
  day: "Day 21",
  title: "Task 1 - Async Await Practice",
  path: "JAVA%20SCRIPT/Assignment/Day21/index.html",
  desc: "Async function, promises and API fetching."
}
3 Push to GitHub

Commit and push your files. The website automatically links the in-page preview, the Live Demo link, and the GitHub source link! 

git add .
git commit -m "Add Day 21 assignment"
git push origin main
