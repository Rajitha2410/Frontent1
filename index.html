CS (Computer Science & Web Architecture)

Fundamental web concepts, HTTP lifecycle, DOM rendering, and core knowledge

Core Concepts
Client-Server & HTTP Lifecycle

The browser (Client) resolves domain names via DNS to IP addresses and issues HTTP/HTTPS requests (GET, POST) to web servers, receiving HTML, CSS, and JS payloads in return.

Client ⇄ DNS ⇄ HTTP Request ⇄ Web Server ⇄ Render
DOM & Rendering Pipeline

Browsers parse raw HTML bytes into tokens, construct the Document Object Model (DOM) tree, combine it with CSSOM to build the Render Tree, calculate layout geometry, and paint pixels.

HTML → DOM + CSSOM → Render Tree → Layout → Paint
Frontend Engineering Standards

Core pillars of modern frontend: Semantic HTML for accessibility (A11y) & SEO, modular responsive CSS with Flex/Grid, modern JavaScript (ES6+), and version control with Git.

Accessibility • Responsiveness • Performance • Clean Code
